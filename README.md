# Shaharul Islam — Personal Portfolio

React (Vite) portfolio with Bangla/English and Dark/Light toggles.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy (Vercel / Netlify)
Import the GitHub repo. Framework: **Vite**, build command `npm run build`, output directory `dist`.

## Customise
- Text (Bangla + English): `src/data/translations.js`
- Projects (title/description in translations, links/tech/images in `src/data/projects.js`)
- Skills: `src/data/skills.js`
- Social links: `src/data/links.js` (add your real LinkedIn URL)
- Profile photo: `public/profile.png`
- CV: replace `public/Shaharul_Islam_CV.pdf` with your own CV
